genoaligner — vendored CPU sources
==================================

The MSA engine and public-API layer in this package are verbatim copies of
files in the sibling C++ repository (github.com/alrobles/genoaligner-devel),
which is where the code is validated. Do not edit them here; upstream fixes
land there and are re-vendored together with this manifest.

  source repo : alrobles/genoaligner-devel

  commit      : 2b15a7a19abc6e8bc2d5b1a2beb751c7b375819c
  vendored on : 2026-09-25; re-verified byte-identical 2026-09-28;
                iterative refinement + FFT anchors vendored 2026-09-28

The .hip files under inst/include/genoaligner/backend/ are host-safe headers
(kernel qualifiers degrade to no-ops without a HIP toolchain); the R package
builds the HOST engine only. src/msa/msa_gpu.cpp, src/msa/nj_gpu.cpp and
src/api/api_msa_gpu.cpp are deliberately NOT vendored (device code).
